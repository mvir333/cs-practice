# Журнал воркшопа по Git

## Раздел 3: Восстановление файла

- git restore lab03/calc.py — отменяет незакоммиченные изменения, возвращая файл к последнему коммиту.
- git restore --source=HEAD~2 lab03/calc.py — берет версию файла из коммита двухкоммитной давности и кладет в рабочую папку.
- Если бы я закоммитила свои правки, git restore не смогла бы их отменить.

## Раздел 2: Сравнение версий и поиск изменений

- git diff показывает разницу между версиями файла.
- git show показывает полную информацию о конкретном коммите.
- git log -S"def" ищет коммиты, где добавлялось слово "def".
- git blame показывает, кто и когда добавил каждую строку.
