# Журнал воркшопа по Git

## 1. Сравнение версий
- git diff показывает разницу между версиями файла.
- git show показывает полную информацию о конкретном коммите (кто, когда, какие изменения).
- git log выводит историю коммитов.
- git log -S"def" ищет коммиты, где добавлялось/удалялось слово "def".
- git blame показывает, кто и когда добавил каждую конкретную строку в файле.

## 2. Восстановление файла
- git restore lab03/calc.py — отменяет незакоммиченные изменения, возвращая файл к последнему коммиту.
- git restore --source=HEAD~2 lab03/calc.py — берет версию файла из коммита двухкоммитной давности.
- Если бы я закоммитила свои правки, git restore не смогла бы их отменить (нужен revert или reset).

## 3. Ошибочный коммит и revert
- git revert HEAD создает новый коммит, который отменяет изменения из предыдущего.
- В опубликованной истории безопаснее revert, так как он не стирает историю для других. git reset --hard переписывает историю, что опасно, если коммит уже был отправлен.
