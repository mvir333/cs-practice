Рабочая папка - директория на диске с файлами проекта, где пользователь напрямую редактирует, создает и удаляет файлы. Индекс - промежуточная область, куда помещаются изменения командой git add перед фиксацией. Коммит - это сохраненная версия изменений с описанием того, что было изменено.
Git - распределенная система контроля версий: локальный инструмент для фиксации изменений, управления ветками и истории правок; работает без интернета, реализуется через CLI. GitHub - облачный хостинг для Git- репозиториев; требует сеть и учетную запись, Git diff - сравнивает рабочую папку vs индекс, показывает изменения, которые еще не подготовлены к коммиту. Git diff --staged - сравнивает индекс vs HEAD (последний коммит); показывает, какие именно изменения попадут в следующий коммит.
